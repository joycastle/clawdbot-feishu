## blockStreaming 问题排查

**现象：** 消息"一股脑"发送，不是实时分条发

**排查过程：**
1. 以为是 `channels.feishu.blockStreaming` 配置问题 → 不是
2. 给飞书插件加了 `onBlockReply` 回调 → 没用
3. 查日志发现 `deliver` 时间间隔只有几百毫秒（而不是我 sleep 的秒数）

**根本原因：** OpenClaw 核心架构问题
- OpenClaw 会缓存整个 agent turn 的所有输出
- 等 turn 结束后才一起发给 dispatcher
- `blockStreaming` 是用于**长文本分块**，不是每次 tool call 后立即发消息

**解决：** 需要改 OpenClaw 核心的 `runFollowupQueue` 或 agent 执行逻辑，让 trae 研究

