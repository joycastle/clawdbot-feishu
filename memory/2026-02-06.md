## dev-lock 和 in-flight 统计（重要！）

查询当前进行中会话数量的命令：
```bash
cd /home/ubuntu/.clawdbot/extensions/feishu && npx tsx src/dev-lock-cli.ts usage
```

返回：
- `inFlightJobs`: 当前正在处理的请求数
- `inFlightUsers`: 有请求在处理中的用户数
- `activeUsers`: 活跃用户数

**用途**：在需要重启/更新前，先查这个确认没有人在用，避免打断别人的会话。

## 技术备忘
- 飞书项目 API 基础 URL: https://project.feishu.cn/open_api
- Token 类型：type=0 是 plugin token (p-开头)，type=1 是 virtual token (v-开头)
- X-USER-KEY 是飞书项目内部的 user_key，不是 open_id
- user_key 获取：在飞书项目页面双击左下角头像
