## Clawdbot Bug #2087 - Synthetic Tool Result 问题

**GitHub Issue:** #2087 "Synthetic tool result causes invalid transcript after terminated tool call"

### 触发条件
1. 发送 "stop" 或中断一个正在执行的 tool call
2. Clawdbot 插入 synthetic error result 来修复 transcript
3. 但 `repairToolUseResultPairing()` 有 bug，把 synthetic result 当 orphan 丢弃
4. 结果：tool_use 在，对应的 tool_result 被丢掉 → API 报错

### 问题代码位置
`dist/agents/session-transcript-repair.js` 的 `repairToolUseResultPairing()` 函数

### 临时解决方案
```bash
rm ~/.clawdbot/agents/main/sessions/<session-id>.jsonl
systemctl --user restart clawdbot-gateway
```

### 根本解决
等 Clawdbot 官方修复 upstream bug。

## 早些时候：版本差异分析

分析了 Clawdbot 版本差距（2026.1.24-3 → 2026.2.9）：
- 官方 feishu extension 几乎没变
- 主要改动在 gateway 层（cron 可靠性、session 管理）
- 品牌变化 clawdbot → openclaw
- 我们的 feishu extension 已大幅定制，跟官方分叉很远
