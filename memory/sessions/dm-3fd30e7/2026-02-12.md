## HTTP API 服务修复

**问题：** 升级 OpenClaw 2026.2.9 后，HTTP API 服务（18793-18799端口）没有随 OpenClaw 启动。

**排查发现：**
- `start-all-apis.ts` 脚本执行后，日志显示服务启动成功，但端口实际没有绑定
- 原因：`main()` 执行完后，Node.js 没有活跃事件循环，进程直接退出

**修复：** 在 `start-all-apis.ts` 末尾添加：
```typescript
// 保持进程活跃
setInterval(() => {}, 1 << 30);
```

**启动命令：**
```bash
cd /home/ubuntu/.clawdbot/extensions/feishu
nohup npx tsx start-all-apis.ts > /tmp/feishu-apis.log 2>&1 &
```

**注意：** 启动后需要等几秒钟端口才能完全 ready。
