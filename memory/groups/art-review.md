## 审核标准

### Merge 活动 - 棋子验收标准
1. 轮廓饱满
2. 色块完整，不能太碎。不需要很多细节，需要Q版
3. 棋子造型要有升级感
4. 每个棋子上半部分要有区分（在遮挡下半部分的时候能明确分别出不同等级的棋子）

### 大地图验收标准
1. 色块完整，不要太碎
2. 路线上的路点间隔均匀
3. 路线不要过直
4. 路点1到画面边缘不能全是陆地，要有空出来的水域方便船进入

### 关卡场景验收标准
1. **构图**
   - 有主次，一眼看出主要展示区域，不能所有区域都很平均
   - 收集物面积尽量大，避开下方UI遮挡区域
2. **收集物**
   - 收集物之间不能太近，避免误触
   - 纵深感要有

### 建造活动 - 建造区域验收标准
1. **区域关联性**
   - 各区域主题突出、功能明确，契合活动题材，且无交叉部分
   - 避免一个区域存在多个主题、和其他区域主题有重合
2. **差异化**
   - 各区域主题需要有较大差异，不能相近或雷同
3. **平衡性**
   - 各区域体量上需平衡，即避免建造物过大或过小，分布过密或过疏
   - 各区域尽量不遮挡影响其他区域
4. **视觉重心引导**
   - 区域划分要有视觉重心引导
