- 每个区域要有明确主题，1个主体建筑+3个配套

- 避免与之前4期重复的元素（旋转类、秋千、望远镜、各种摊位等）
- 避免宗教元素
- 迎宾大门不用兔子（爱丽丝主题用过）
- 动画制作流程限制：避免旋转动画

### 飞书插件开发经验补充
- Vertex AI 上 Gemini 3 系列模型名带 `-preview` 后缀（如 `gemini-3-pro-preview`、`gemini-3-flash-preview`）
- 不带 `-preview` 会 404
- 飞书视频消息 content JSON 包含 `duration`（毫秒）、`file_key`（视频）、`image_key`（缩略图）
- **必须 hard restart（clawdbot gateway restart）才能重新编译 TypeScript 扩展**，SIGUSR1 软重启不够
