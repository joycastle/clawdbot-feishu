# FAQ 常见问题

> 遇到问题？先看这里

---

## 🧠 Q1: 王总失忆了怎么办？

**症状：** session 压缩失败、上下文丢失、不记得刚才聊了什么

**解决方案：**
1. 提醒王总：「拉一下飞书聊天历史补全上下文」
2. 王总会用 CLI 工具拉取最近的聊天记录：
   ```bash
   npx tsx ~/.clawdbot/extensions/feishu/src/cli/history.ts --message <message_id> --count 20
   ```
3. 如果是回复某条消息导致的上下文断裂，把那条消息的 message_id 告诉王总

**预防：** 重要对话中途可以让王总把关键内容写到 memory 文件

---

## 💳 Q2: Opus 额度超限了怎么办？

**症状：** 回复变慢或报错、提示 rate limit / 429

**解决方案：**
1. **先试 `/new`** — 开个新会话，上下文清空后可能就不超限了
2. 如果还是不行，切模型：`/model gemini` 或 `/model sonnet`
3. 等额度恢复后切回来：`/model opus`

**可用模型：**
- `opus` - 最强，但有额度限制
- `sonnet` - 次强，额度相对宽松
- `gemini` - Google 模型，备用

**小知识：** 429 通常是上下文太长导致的，/new 清空上下文后往往能解决

---

## 📝 Q3: 怎么让王总记住标准规范？

**症状：** 告诉王总某个规范/流程后，下次又忘了

**解决方案：**
1. 明确告诉王总：「把这个写到长期记忆里」或「持久化这个规范」
2. 王总会把内容写入：
   - `MEMORY.md` - 长期记忆（重要规范、偏好）
   - `memory/YYYY-MM-DD.md` - 当日记录
   - 相关的 memory 子文件（如 `memory/groups/xxx.md`）

**关键点：**
- 口头说的内容不会自动记住
- 必须明确要求写入文件才能持久化
- 重要规范建议写入 MEMORY.md 或专门的规范文档

## 🆘 Q4: 搞不定怎么办？

**终极方案：** 找 **@宝根**

适用场景：
- 上面的方法都试过了还是不行
- 遇到技术问题或 bug
- 需要修改配置或权限
- 其他搞不定的情况

## 💡 小贴士

1. **检查状态：** 发 `/status` 看当前模型和 session 状态
2. **重开会话：** 发 `/new` 开始新对话（会丢失当前上下文）
3. **查看指令：** 发 `/helper clawdbot` 看完整指令列表
