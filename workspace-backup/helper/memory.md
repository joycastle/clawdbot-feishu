# 记忆系统

> 我的记忆层结构详解

---

## 📁 整体结构

```
~/clawd/                     # 工作空间根目录
├── 核心文件（Clawdbot 标准）
│   ├── AGENTS.md            # 行为准则
│   ├── SOUL.md              # 核心人格
│   ├── IDENTITY.md          # 身份设定（王总）
│   ├── USER.md              # 用户信息
│   ├── MEMORY.md            # 长期记忆 ⭐
│   ├── TOOLS.md             # 工具索引
│   └── HEARTBEAT.md         # 心跳任务
│
└── memory/                  # 记忆目录
    ├── YYYY-MM-DD.md        # 每日记录 ⭐
    ├── groups/              # 群聊规则
    ├── sessions/            # 会话记忆
    ├── tools/               # 工具文档
    ├── welcome/             # 欢迎配置
    ├── sheets/              # 表格结构
    └── 专项文档...
```

---

## 🧠 记忆分层

| 层级 | 位置 | 用途 | 持久性 |
|------|------|------|--------|
| **长期** | `MEMORY.md` | 重要规范、偏好、持久知识 | 永久 |
| **短期** | `memory/YYYY-MM-DD.md` | 当日记录、临时笔记 | 按日 |
| **群聊** | `memory/groups/*.md` | 各群独立规则 | 永久 |
| **会话** | `memory/sessions/` | 特定会话的独立记忆 | 按需 |
| **工具** | `memory/tools/*.md` | API 使用说明 | 永久 |

---

## ⭐ 长期记忆 (MEMORY.md)

**什么该写入：**
- 用户偏好和习惯
- 重要决策和结论
- 反复用到的规范
- 教训和经验

**什么不该写入：**
- 临时事项（写 daily notes）
- 敏感信息（凭证、密码）
- 会过时的信息

---

## 📅 每日记录 (memory/YYYY-MM-DD.md)

**自动写入：**
- 重要对话摘要
- 完成的任务
- 学到的知识点
- 踩过的坑

**每天启动时读取今天和昨天的记录**

## 💡 如何让我记住

1. **临时事项** → 「记一下」「写到今天的记录里」
2. **长期规范** → 「写到长期记忆」「持久化这个」
3. **群聊规则** → 「这个群的规则是...」

⚠️ 口头说的不会自动记住，必须明确要求写入文件

## 📢 广播功能

更新了重要提示词/规则后，可以通知其他活跃 session 同步。

**什么时候用：**
- 新增/修改了 AGENTS.md、MEMORY.md 的重要规则
- 更新了群聊规则
- 发现并修复了错误的习惯

**如何使用：**
```bash
# 查看活跃 session
curl http://127.0.0.1:18799/sessions

# 广播通知
curl -X POST http://127.0.0.1:18799/broadcast \
  -H "Content-Type: application/json" \
  -d '{"message": "📢 约定更新：xxx", "filter": "feishu"}'
```

**注意：** 不要频繁广播，只在重要更新时使用
