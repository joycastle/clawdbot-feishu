# 状态指令 (State Commands)

> 快速了解系统当前状态的三个指令

---

## 📊 使用状态

**含义**：查看系统当前负载情况

**查询内容**：
- `inFlightJobs` - 正在处理中的任务数
- `inFlightUsers` - 有任务在处理中的用户数
- `activeUsers` - 近10分钟内有活动的用户数

**使用场景**：
- 想知道系统忙不忙
- 排查为什么响应慢
- 确认是否有任务卡住

**内部实现**：调用 dev-lock 模块的 `getUsageSnapshot()` 函数

---

## 🧠 上下文状态

**含义**：查看当前会话的详细信息

**查询内容**：
- 当前使用的模型（如 `anthropic/claude-opus-4-5`）
- Context 用量（如 `0/200k (0%)`）
- Compactions 次数（上下文压缩次数）
- Thinking 状态（开/关）
- 会话标识和最后更新时间

**使用场景**：
- 想知道当前用的是哪个模型
- 检查 context 是否快满了
- 确认 thinking 模式状态

**内部实现**：调用 `session_status` 工具

---

## ⏰ 任务状态

**含义**：查看定时任务队列

**查询内容**：
- 所有 cron job 列表
- 每个任务的名称、schedule 表达式
- 下次执行时间（nextRunAtMs）
- 最后执行状态（ok/error）
- 最后执行耗时

**使用场景**：
- 查看有哪些定时任务在跑
- 排查某个任务是否正常执行
- 确认任务下次什么时候触发

**内部实现**：调用 `cron list` 命令

---

## 快速指令

| 说法 | 触发 |
|------|------|
| "使用状态" / "负载" / "系统忙吗" | → 使用状态 |
| "上下文状态" / "session" / "用的什么模型" | → 上下文状态 |
| "任务状态" / "cron" / "定时任务" | → 任务状态 |
| "全部状态" / "状态" | → 三个都查 |
