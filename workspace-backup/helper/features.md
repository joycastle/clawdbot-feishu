# 功能总览

> 王总能做什么？

---

## 🤖 Clawdbot 原生

| 能力 | 说明 |
|------|------|
| 多模型切换 | `/model opus` `/model gemini` |
| 定时任务 | Cron 调度、定时提醒 |
| 浏览器自动化 | 网页操作、截图 |
| 文件/Shell | 读写文件、执行命令 |
| 网页搜索/抓取 | 搜索 + 内容提取 |
| 子代理 | 并行处理任务 |
| TTS | 文字转语音 |

---

## 📱 飞书能力

| 能力 | 说明 |
|------|------|
| **随时打断** | 发新消息即可打断当前处理，自动开始处理新请求 |
| 飞书项目 | 工作项、缺陷、任务、评论 |
| 表格/多维表格 | 读取、搜索数据 |
| 云文档 | 读取文档内容 |
| 聊天历史 | 拉取消息补上下文 |
| 表情反应 | 给消息加 emoji |
| 消息卡片 | 富文本、表格卡片 |
| 视频分析 | 多维表格视频 → Gemini |
| 日志分析 | 玩家日志 → Gemini 分析异常 |
| 欢迎新人 | 自动欢迎 + 岗位文档 |
