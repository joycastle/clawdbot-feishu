# 游戏美术审核标准

> 来源：2026-02-10 群内讨论

---

## 1. Merge活动 - 棋子验收标准

| 项目 | 标准 |
|------|------|
| 轮廓 | 饱满 |
| 色块 | 完整，不能太碎 |
| 细节 | 不需要很多细节，需要Q版 |
| 造型 | 要有升级感 |
| 区分度 | 每个棋子上半部分要有区分（遮挡下半部分时能明确分辨不同等级） |

---

## 2. 大地图验收标准

| 项目 | 标准 |
|------|------|
| 色块 | 完整，不要太碎 |
| 路点 | 路线上的路点间隔均匀 |
| 路线 | 不要过直 |
| 边缘 | 路点1到画面边缘不能全是陆地，要有空出来的水域方便船进入 |

## 3. 关卡验收标准

### 3.1 关卡场景

#### 构图
- 有主次，能一眼看出主要想展示的区域，不能所有区域都很平均
- 收集物占的面积尽量大，避开下方UI遮挡区域

#### 颜色
- 色彩丰富：主色调60%，副色调30%，点缀10%

#### 初始状态（无收集物）
- 要显得**空**：和有收集物状态对比明显，该留白的地方要留白
- 不能**苍白**：物品上少，但是场景的细节要足够支撑画面

#### 全收集状态
- 一眼能看到画面重心
- 收集物不能过小

### 3.2 场景收集物
- 在画面中合理
- 尽量结构可拆分
- 有故事感，看到收集物就能想象到场景中发生的故事（可选）

---

## 4. 关卡需求标准

### 4.1 关卡主题

#### 章节主题关联性
- 要选有代表性，能突出章节主题特性的画面
- 避免选择无特色、和多个主题适配的画面

#### 差异化
- 相邻关卡 & 章节之间，不能雷同

#### 故事性（非必须，部分章节主题适用）
- 关卡之间能有逻辑顺序关联，相当于故事推进的各个情节

### 4.2 关卡描述

#### 氛围描述
- 明确关卡的初始状态，传达出的整体氛围感受
- 对于时间、色调有要求需标明
- 明确场景近、中、远景内容（可选）

#### 收集物
- 面积尽量大，8个收集物整体面积尽量占到 **1/3 到 1/2**
- 如果是成组的收集物，明确收集物内所有物品
- 收集物位置（可选）

### 4.3 关卡参考图

#### 构图
- 有主次，主要区域占画面整体 **1/3 到 1/2**

#### 画风
- 参考图的画风要和游戏内风格一致

## 5. 建造活动验收标准

> 来源：2026-02-10 黄桃发送

### 5.1 建造区域

| 项目 | 标准 |
|------|------|
| 区域关联性 | 各区域主题突出、功能明确，契合活动题材，无交叉；避免一个区域多主题或与其他区域重合 |
| 差异化 | 各区域主题需有较大差异，不能相近或雷同 |
| 平衡性 | 各区域体量平衡，避免建造物过大/过小、分布过密/过疏；尽量不遮挡其他区域 |
| 视觉重心引导 | 区域划分需引导视觉重心 |
