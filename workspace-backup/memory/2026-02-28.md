# 2026-02-28 Daily Notes

## Compaction Safeguard 补丁修复（第二版）

### 问题
2/26 的补丁只打了一半生效：
- `compaction-safeguard.js` ✅ 有 RUNTIME_REGISTRY 和 getter/setter
- 但 `hasRuntime: false`，说明 runtime 获取不到

### 根因
补丁用 `WeakMap` 以 sessionManager 对象引用为 key，但：
- `params.sessionManager`（set 时）和 `ctx.sessionManager`（get 时）**不是同一个对象实例**
- WeakMap 用引用相等，不同实例找不到

### 修复
改用 `Map<string, RuntimeInfo>`，以 `sessionManager.sessionId` 为 key：
```javascript
// 旧: WeakMap + 对象引用
const RUNTIME_REGISTRY = new WeakMap();
const key = sessionManager;

// 新: Map + sessionId
const RUNTIME_REGISTRY = new Map();
const key = sessionManager?.sessionId;
```

### 调试日志
```
[compaction-safeguard] 📝 Registered runtime for sessionId: xxx
[compaction-safeguard] 🔍 Lookup runtime for sessionId: xxx found: true/false
```

### 注意
- 改的是 npm 包编译后的 JS，`npm update clawdbot` 会覆盖
- 需要向 clawdbot 官方提 PR 或保留 patch 脚本
