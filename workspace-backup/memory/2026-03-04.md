## 飞书状态卡片功能 (statusCard) ⭐

实现了对话中断功能，用状态卡片替代 typing indicator：

### 新增文件
- `/home/ubuntu/.clawdbot/extensions/feishu/src/features/status-card.ts`
  - `sendStatusCard()` - 发送"处理中"卡片
  - `updateStatusCard()` - 更新为"已完成"/"已中断"
  - `deleteStatusCard()` - 3秒后自动删除
  - `isStatusCardAbortAction()` - 检测中断按钮点击
  - `buildAbortedCard()` - 构建已中断状态卡片

### 修改文件
- `reply-dispatcher.ts` - 集成状态卡片，每个 turn 只发一个
- `config-schema.ts` - 添加 `statusCard: boolean` 配置项
- `monitor.ts` - 处理中断按钮点击回调

### 配置
```json
{
  "channels": {
    "feishu": {
      "statusCard": true
    }
  }
}
```
