# 飞书项目 User Key 表

> 飞书项目内部的 user_key，用于 API 调用时的 X-USER-KEY header 和字段赋值

## ⚠️ 重要规矩

**user_key 只许调用者自己用，除非本人授权！**

- A 让我帮忙处理飞书项目 → 用 A 的 user_key ✅
- B 让我帮 A 处理 → 私聊通知 A："B 想用你的 user_key 帮你处理 xxx，你同意吗？"
  - A 同意 → 可以操作 ✅
  - A 不同意或不回复 → 不操作，告诉 B 结果

不能偷偷用别人的 user_key，必须经过本人同意。

## 获取方式

1. 进入飞书项目（project.feishu.cn）
2. 点击左下角头像，弹出个人信息卡片
3. **双击**卡片里的小头像 → 自动复制 user_key 到剪贴板
4. 粘贴即可

注意：不是单击，是双击头像才会复制！
