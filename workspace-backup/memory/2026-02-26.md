## Compaction Summary 失败问题调查

### 问题现象
- 上下文断了，summary 显示 "Summary unavailable due to context limits. Older messages were truncated."
- 日志显示 compaction 触发了（有 start + retry），但没有生成真正的 summary

### 关键发现
1. **Session JSONL 记录**：
   ```json
   {
     "type": "compaction",
     "summary": "Summary unavailable due to context limits...",
     "tokensBefore": 360402,
     "fromHook": true
   }
   ```

2. **根因分析**：
   - `compaction.mode: "safeguard"` 启用了 clawdbot 的 compaction-safeguard 扩展
   - 该扩展在 `ctx.model` 为 undefined 时使用 fallback summary
   - 代码路径：`~/.npm-global/lib/node_modules/clawdbot/dist/agents/pi-extensions/compaction-safeguard.js`

3. **代码逻辑**：
   ```javascript
   const model = ctx.model;
   if (!model) {
       return { compaction: { summary: fallbackSummary, ... } };
   }
   ```

4. **可能原因**：
   - `ctx.model` 通过 `extensionRunner.getModel()` 动态获取
   - 在 compaction 触发时，model state 可能不稳定或未正确传递

### 待尝试方案
- 将 `agents.defaults.compaction.mode` 从 `"safeguard"` 改为 `"default"`
- 这会使用 Pi 内置的 compaction 逻辑而非 clawdbot 扩展

- 配置：`~/.clawdbot/clawdbot.json`
- 日志：`~/.clawdbot/logs/clawdbot-YYYY-MM-DD.log`

## Compaction Safeguard 补丁（已应用）

### 精确根因（与 GPT 对齐）
- **不是**模型调用失败/超时/限流
- **是** `ctx.model === undefined`，根本没尝试调用模型就走了 fallback
- 证据：25ms 时间差（真调 Opus 应该几秒）
- 旧逻辑问题：截断历史 + 写占位摘要 = 两头都没捞着

### 为什么 ctx.model 是 undefined？
在 embedded compaction 链路里，model 没有被正确注入到扩展执行上下文。

### 解决方案（GPT 补丁）
把 model 通过 session 级 runtime 明确传给扩展；扩展侧优先用 ctx.model，没有就用 runtime.model；都没有就 cancel compaction，绝不截断历史+写占位摘要。

### 核心改动

**1. extensions.js**：注册 runtime
```javascript
import { setCompactionSafeguardRuntime } from "../pi-extensions/compaction-safeguard.js";
// ...
if (resolveCompactionMode(params.cfg) === "safeguard") {
    paths.push(resolvePiExtensionPath("compaction-safeguard"));
    setCompactionSafeguardRuntime(params.sessionManager, {
        contextWindowTokens: resolveContextWindowTokens(params),
        model: params.model,
    });
}
```

**2. compaction-safeguard.js**：
```javascript
// 新增 runtime registry
const RUNTIME_REGISTRY = new WeakMap();
export function setCompactionSafeguardRuntime(sessionManager, value) { ... }
export function getCompactionSafeguardRuntime(sessionManager) { ... }

// model 兜底
const runtime = getCompactionSafeguardRuntime(ctx.sessionManager);
const model = ctx.model ?? runtime?.model;

// 缺失时取消压缩而非 fallback（保留历史）
if (!model) {
    console.warn("[compaction-safeguard] Missing model context. Cancelling compaction to preserve history.");
    return { cancel: true };
}
```

**3. 补充改动**：
- `contextWindowTokens` 优先用 runtime 传入值
- `maxHistoryShare` 可配置，默认 0.5
- `maxHistoryTokens` 计算加入 `SAFETY_MARGIN`
